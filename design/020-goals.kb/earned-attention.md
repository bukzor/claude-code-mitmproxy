# Earned attention

> Agent-inferred and vetoable. This entry names a theory the code already
> follows; the operator has not ratified the framing, and a later session may
> reword or reject it without treating anything below as settled.

[`earned-silence`] binds the system: it may not stay quiet about an anomaly
unless it holds evidence the quiet is correct. That leaves the opposite
direction unbound, and this project spent it freely -- a standing list of
duties, each asking for a visit whether or not anything had happened. Triage
the queue. Run the collector. Run the checkers after editing their inputs.
Read the capture inventory and see whether upstream shipped new text.

The cost is not the minutes. It is that a duty carried by memory is a silent
failure point of exactly the kind `earned-silence` exists to forbid. Skipping
one produces no signal, so the system's quiet stops meaning anything: the
tripwires still fire, but they are calibrated against a fixture nobody
refreshed, or they are drowned in a queue nobody drained. `earned-silence`
was written after a patch went dark for months. A duty nobody performs fails
the same way, one rung out -- and it is worse, because the mechanism looks
healthy the whole time.

So attention must be earned too, and by the same standard: the operator may be
asked to look only when something holds evidence there is anything to see. A
standing instruction to look is not that evidence. It is a guess, made once,
that the answer will be interesting often enough to be worth the visits --
and the guess is wrong every time nothing happened, which is most times.

Success looks like: the operator's standing obligations are exactly the ones
the system cannot discharge on its own, and each of the others has been either
bound to the occasion that creates it, argued away by showing that nothing is
lost when nobody looks, or converted into a signal that arrives by itself.
What is left over is judgment -- deciding what upstream's new wording means
for a patch -- which no amount of scheduling can absorb, and which is
precisely what the freed attention is for.

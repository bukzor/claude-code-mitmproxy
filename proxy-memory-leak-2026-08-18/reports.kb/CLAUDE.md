# Upstream contributions

Outbound contributions to upstream trackers born from this
investigation, one per file; frontmatter per `../reports.jsonschema.yaml`
(`target`, `status`, `posted-url`). Three kinds, same lifecycle:

- new bug reports
- evidence/root-cause added to preexisting issues where maintainers or
  users lack information
- workarounds posted where affected users will search

Belongs: the draft body as it will be posted, plus enough preamble to
know where, how, and in what order to post it.
Does not belong: the analysis itself (`../findings.kb/`,
`../evidence.kb/` -- drafts cite, never duplicate).

Posting is outward-facing: needs the user's go-ahead (or the user
posts). On posting, flip `status: posted` and record `posted-url`.

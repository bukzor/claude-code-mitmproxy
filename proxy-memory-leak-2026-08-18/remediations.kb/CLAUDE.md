# Remediations

`../remediations.jsonschema.yaml` (`status`, `requires-sudo`).

Belongs: concrete measures addressing this incident class -- what to do,
why it helps, exact commands.
Does not belong: diagnosis (`../findings.kb/`, `../root-cause.kb/`).

Flip `status` as measures are decided/applied; note the date and any
deviation from the written commands in the file body.

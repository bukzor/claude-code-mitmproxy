# promotion.refused

The commit hook rejected the promotion, and its output follows the line
(pytest timings stripped, so the text reads the same each pass). The
fixture stays on disk, named and uncommitted, and every pass takes it up
again until the commit stands: the line prints once, and the fix is what
makes it go away. Deleting the fixture only refiles it.

Read which property failed. `check_strip_floors` is the usual one: the
fixture carries a session-optional block inside its core, inflating that
shape's `_strip-rate` floor, and the fix is a `blocks.d/` rule for the block
(`blocks.d/README.md`). A red `check_patches` is a patch whose target
upstream changed: `CLAUDE.kb/patch-failure-triage.md`.

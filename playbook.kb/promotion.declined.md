# promotion.declined

A prompt copy whose body carries no marker this repo knows, so it has no
shape and no derivable name; the line names the raw capture to read. This
is the one drift worth reading rather than filing: upstream restructured the
prompt. Addressing it is a marker in `prompt_shape.SHAPE_MARKERS` and a
suffix in `FIXTURE_SUFFIX` for the new shape, after which the next pass
files it. The line repeats every pass until then.
